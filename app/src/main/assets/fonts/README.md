# Font Assets

Place the following font files here for the settings page to use them:

- `Metamorphous-Regular.ttf` — [Google Fonts](https://fonts.google.com/specimen/Metamorphous)
- `SpaceGrotesk-Regular.ttf` — [Google Fonts](https://fonts.google.com/specimen/Space+Grotesk)

If fonts are missing, the app gracefully falls back to system Serif font.

> **Note:** These fonts are only used in the settings page (Jetpack Compose).
> The widget uses system font approximations due to Android RemoteViews limitations.
